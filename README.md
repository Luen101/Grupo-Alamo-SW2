# Grupo Alamo - Ingeniería del Software II

## Descripción del repositorio
Este repositorio centraliza todas las prácticas, investigaciones y proyectos desarrollados por el Grupo Alamo para la asignatura **Ingeniería del Software II**. Abarca desde la documentación técnica, diagramado de arquitectura, historias de usuario y código fuente desarrollados bajo marcos ágiles, integración continua (CI/CD) y buenas prácticas de ingeniería de software para la entrega continua de valor.
