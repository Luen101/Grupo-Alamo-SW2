## 📄 Descripción del repositorio
Este repositorio centraliza todas las prácticas, investigaciones y proyectos desarrollados por el Grupo Alamo para la asignatura **Ingeniería del Software II**. Abarca desde la documentación técnica, diagramado de arquitectura, historias de usuario y código fuente desarrollados bajo marcos ágiles, integración continua (CI/CD) y buenas prácticas de ingeniería de software para la entrega continua de valor.

## 📂 Estructura del Repositorio

El repositorio está dividido de forma modular según las unidades y productos asignados durante el semestre:

| Producto | Contenido | 
| :--- | :--- | 
| **📁PRODUCTO 1** |**Fundamentos de la Gestión de Proyectos y Productos de Software:** Crisis del software, era ágil/DevOps, ingeniería de requisitos, PMBOK 7, SWEBOK V4 e ISO 29148. | 
| **📁PRODUCTO 2** |**Planificación y Ciclos de Vida del Software:** Artefactos de visión, Acta de Constitución, Lean Canvas, selección de ciclos de vida y WBS (EDT) a 16 semanas. |
| **📁PRODUCTO 3** |**Estimación en Entornos Complejos:** Enfoques clásicos (PERT, CPM, Gantt) y contemporáneos (estimación relativa, métricas de flujo, Monte Carlo, Ley de Brooks y deuda técnica). |
| **📁PRODUCTO 4** | **Gestión de Riesgos y Deuda Técnica:** Análisis cualitativo/cuantitativo, amenazas modernas (ciberseguridad, cloud, IA, terceros) y gobernanza de riesgos en entornos distribuidos. | 
| **📁PRODUCTO 5** | **Integración Continua, Entrega Continua y Despliegue (CI/CD):** Automatización de pipelines, integración continua, pruebas y estrategias de despliegue continuo. |
| **📁PRODUCTO 6** |**Liderazgo, Equipos y Cultura de Ingeniería:** Estructuras de equipos, liderazgo en ingeniería de software, métricas de rendimiento y cultura organizacional. |
| **📁PRODUCTO 7** | **Monitoreo, Calidad, Cierre y Transición a Operaciones:** Control de calidad, monitoreo continuo, retrospectiva, cierre de proyecto y transición a operaciones. |
